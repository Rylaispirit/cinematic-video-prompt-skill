# Composition — Bố cục

Sắp xếp các yếu tố trong khung hình. Dùng cho ảnh tĩnh và khung hình đầu của clip video.

## Quy tắc nền tảng
| Prompt (EN) | Giải thích (VI) |
|---|---|
| rule of thirds | Quy tắc 1/3 |
| Grid of Nine | Lưới 3x3, lấp đầy cả 9 ô cân bằng |
| golden ratio / fibonacci spiral | Tỷ lệ vàng / vòng xoắn Fibonacci |
| The Golden Section / Golden Mean | Chia không gian theo tỷ lệ 1:1.618 |
| Spiral Rule | Đường xoắn ốc dẫn mắt vào sâu |
| Dynamic Symmetry | Hệ bố cục theo tỷ lệ và đường chéo, hội họa cổ điển |
| The Crosshair Method | Yếu tố quan trọng tại giao điểm dấu cộng giữa khung |
| Rule of Odds | Số chủ thể lẻ (3, 5), hài hòa hơn |
| Grouping of Threes | Nhóm ba vật thể |
| Rule of Space | Không gian rộng phía trước hướng di chuyển |
| Breathing Room / Look Space | Khoảng trống trước hướng nhìn, ảnh "dễ thở" |
| Headroom and Lead Room | Kiểm soát khoảng trống trên đầu và trước hướng nhìn |

## Đường dẫn & hình dạng
| Prompt (EN) | Giải thích (VI) |
|---|---|
| leading lines | Đường dẫn hướng mắt người xem |
| Implied Lines | Đường dẫn vô hình từ hướng nhìn, cử chỉ |
| Gaze Direction | Dùng hướng nhìn của nhân vật để dẫn mắt |
| Diagonal Lines / Diagonal Placement | Đường chéo mạnh, năng động, chuyển động |
| Curved Lines | Đường cong mềm (sông, đường uốn lượn) dẫn mắt nhẹ nhàng |
| S-Curve Composition | Đường chữ S mềm mại, gợi cảm |
| Z-Shape Composition | Hình chữ Z dẫn mắt qua toàn khung |
| L-Shape Composition | Hình chữ L |
| Triangular Composition | Tam giác (hoặc lộn ngược): ổn định hoặc năng động |
| Circular Composition | Vòng tròn/vòng cung: thống nhất, khép kín |
| The Vanishing Point | Điểm tụ tạo phối cảnh sâu, hướng vào vô tận |
| Leading the Eye to the Apex | Dẫn mắt tới điểm cao nhất trong khung |
| Implied Motion | Sắp xếp tạo cảm giác chuyển động mạnh |
| Tunneling Effect | Tiền cảnh + hậu cảnh tạo cảm giác nhìn qua đường hầm |

## Cân bằng & đối xứng
| Prompt (EN) | Giải thích (VI) |
|---|---|
| symmetry / Central Axis Symmetry | Đối xứng hoàn hảo qua trục, trang nghiêm, quyền lực |
| Symmetry (Broken) | Gần đối xứng nhưng có chi tiết phá vỡ, tạo điểm nhấn |
| Centred Composition | Chủ thể chính giữa, trực diện, mạnh mẽ |
| Asymmetrical Balance | Không đối xứng nhưng cân bằng trọng lượng thị giác |
| Dynamic Balance | Cân bằng bởi các yếu tố không đồng nhất |
| Balancing Elements | Vật nhỏ đối diện cân với chủ thể lớn |
| Balance by Color/Value | Mảng màu rực nhỏ đối trọng mảng tối lớn |
| Visual Weight Distribution | Phân bổ sức nặng màu sắc, độ sáng, chi tiết |
| Unbalanced Composition (Intentional) | Cố ý lệch một bên, căng thẳng, sắp đổ |
| Static Composition | Nhiều đường ngang dọc, tĩnh lặng, trang trọng |
| Harmonic Arrangement | Cân bằng dễ chịu tuyệt đối, kiến trúc, tĩnh vật |
| Tonal Harmony | Hài hòa tông sáng/tối |

## Không gian & chiều sâu
| Prompt (EN) | Giải thích (VI) |
|---|---|
| negative space | Khoảng trống lớn làm nổi chủ thể |
| Isolation of Subject / Central Isolation | Chủ thể tách biệt, cô đơn, nhỏ giữa không gian rộng |
| Filling the Frame | Chủ thể lấp đầy khung, thân mật, chi tiết |
| Break the Frame | Chủ thể "vượt ra" khỏi viền khung, hiệu ứng 3D |
| Open Composition | Cảnh kéo dài ra ngoài khung, vô tận |
| Closed Composition | Mọi yếu tố gọn trong khung, cô lập, hoàn chỉnh |
| framing / Framing within a Frame | Dùng cửa sổ, vòm, gương bao quanh chủ thể |
| Foreground Interest | Vật thú vị sắc nét ở tiền cảnh, tăng chiều sâu |
| Repoussoir | Vật lớn tối ở tiền cảnh (góc) đẩy chủ thể lùi lại |
| Depth of Field Stacking | Nhiều lớp nét: tiền, trung, hậu cảnh |
| Shallow/Deep Perspective | Chiều sâu rất nông hoặc rất sâu |
| Overlapping Subjects | Vật chồng lên nhau một chút, phân lớp |
| Focal Length Compression | Tele nén không gian, vật xa gần trông gần nhau |
| Focal Length Expansion | Góc rộng phóng đại tiền cảnh, nhấn khoảng cách |
| Near-Far Juxtaposition | Vật rất gần + rất xa |
| Worm's-Eye Perspective (Compositional) | Từ dưới hất lên, chủ thể vĩ đại |
| Aerial View (Compositional) | Từ trên cao, cảnh vật thành hình khối phẳng |
| Viewpoint (Unique/Unconventional) | Góc nhìn bất thường, bất ngờ |
| Vignetting (Compositional) | Tối viền có chủ đích, tập trung trung tâm |
| Panoramic Composition | Siêu ngang, 21:9 |
