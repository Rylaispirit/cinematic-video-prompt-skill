# Lighting — Ánh sáng

Điều khiển không khí và cảm xúc của tác phẩm. Chọn 1–2 từ khóa mỗi prompt; ánh sáng phải khớp thời tiết và thời điểm trong ngày.

## Ánh sáng tự nhiên & thời điểm
| Prompt (EN) | Giải thích (VI) |
|---|---|
| golden hour | Hoàng hôn/bình minh ấm áp, thơ mộng |
| Magic Hour with Sun-Kissed Effect | Hoàng hôn/bình minh ấm, da chủ thể được nắng "hôn" nhẹ |
| blue hour | Xanh huyền ảo ngay trước bình minh / sau hoàng hôn |
| Direct Sunlight (Midday) | Nắng trực tiếp giữa trưa, trắng/xanh, rất gắt, bóng cực sắc |
| Overcast Light (Flat Light) | Trời nhiều mây, không bóng sắc, màu trung thực, ít kịch tính |
| Window Light (Soft & Diffused) | Ánh sáng cửa sổ dịu, khuếch tán, thanh bình |
| dappled light | Nắng lốm đốm xuyên qua tán lá |
| crepuscular rays | Tia sáng mặt trời rẽ qua đám mây |
| volumetric lighting | Luồng tia sáng thấy rõ trong không khí |
| Sunburst Effect | Tia sáng loe ra nhiều cánh khi qua vật cản nhỏ (khe cửa, ngón tay) |
| Backlit with strong lens flare | Ngược sáng mạnh + lóe ống kính rõ rệt, điện ảnh |
| backlighting | Sáng chiếu từ phía sau chủ thể |
| silhouette | Bóng đen của chủ thể trên nền sáng |
| Cinematic Sunset Over Water | Hoàng hôn kịch tính phản chiếu trên mặt nước |
| Atmospheric Perspective | Vật xa mờ và nhạt hơn do không khí, tăng cảm giác khoảng cách |
| Haze/Atmosphere Effect | Lớp sương nhẹ để ánh sáng có vẻ dày, thấy đường đi |
| Environmental Lighting | Ánh sáng phản xạ từ môi trường xung quanh |
| Global Illumination (GI) | Ánh sáng nảy chân thực giữa các bề mặt |
| Diffused Ambient Light | Ánh sáng môi trường khuếch tán, không có nguồn rõ ràng |
| Ambient Occlusion | Bóng tối tinh tế ở góc khuất, khe hẹp, tăng chiều sâu |
| High Dynamic Range (HDR) Lighting | Dải tương phản rộng, giữ chi tiết cả vùng sáng và tối |
| bioluminescence | Phát quang sinh học, kỳ ảo |
| fireworks | Ánh sáng pháo hoa |

## Ánh sáng studio & chân dung
| Prompt (EN) | Giải thích (VI) |
|---|---|
| studio lighting | Ánh sáng chuyên nghiệp trong phòng chụp |
| soft light | Mềm mại, tình cảm, bóng mịn |
| hard light | Gắt, kịch tính, bóng sắc |
| rim lighting | Viền sáng tách chủ thể khỏi hậu cảnh |
| Rim Light (Subtle) | Viền rất nhẹ, chỉ đủ tách chủ thể tinh tế |
| Edge Lighting | Sáng tập trung vào cạnh vật thể, nhấn đường nét |
| rembrandt lighting / Rembrandt Triangle | Chân dung cổ điển, tam giác sáng trên má bên tối |
| Softbox Lighting | Mềm, khuếch tán, lý tưởng chân dung |
| Octabox Lighting | Siêu mềm và rộng, chân dung toàn thân |
| Hard Studio Light (Beauty Dish) | Gắt nhưng vùng sáng tròn, chân dung làm đẹp |
| Studio Strobe Lighting | Flash mạnh, sắc như studio thời trang |
| Two-point Lighting | Key + Fill, cân bằng sáng tối, phỏng vấn |
| High Side Lighting | Từ cao và hơi nghiêng phía trước, nổi cấu trúc xương mặt |
| Grid Lighting | Lưới chắn thu hẹp luồng sáng, tập trung có hướng |
| Snoot Effect | Sáng cô lập thành vòng tròn nhỏ chiếu mạnh vào một điểm |
| Gobo Lighting | Bị chặn một phần tạo hoa văn/bóng (bóng cửa sổ) |
| Gel Lighting | Tấm lọc màu trên đèn, ánh sáng đơn/đa sắc nổi bật |
| Specular Highlights | Điểm sáng phản chiếu (kim loại, mắt, nước) rõ và sắc |
| Reflective Catchlight | Điểm sáng phản chiếu trong mắt phải nổi bật |
| Reflective Surface Bouncing Light | Sáng phản chiếu từ bề mặt gần (sàn trắng), thêm nguồn phụ |
| spotlight | Sân khấu, tập trung một điểm |
| Spotlight vs Floodlight | Spotlight: hẹp, mạnh; Floodlight: rộng, tỏa, làm nền |
| Warm Fill with Cool Key | Key lạnh (xanh) + Fill ấm (cam), hiệu ứng tách biệt |
